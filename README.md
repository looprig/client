# client

`github.com/looprig/client` is a framework-neutral TypeScript session SDK plus
a Go backend-for-frontend (BFF) for looprig. It lets any web frontend attach
to a looprig session's read plane, and ships a reference Svelte web app built
on top of the SDK.

This module implements the design in
[`harness/docs/plans/2026-07-02-client-web-app-design.md`](../harness/docs/plans/2026-07-02-client-web-app-design.md).

The module is under active construction. See
[`harness/docs/plans/2026-08-10-client-module-implementation.md`](../harness/docs/plans/2026-08-10-client-module-implementation.md)
for the current implementation plan and task breakdown.
